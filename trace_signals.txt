# [CONSUMERS]
#   build.rs  : Parses registry -> emits `pub const TRACE_<NAME>` into src/trace.rs.
#               Invariants: duplicate <slot> or <NAME> = build error.
#   plate.py  : Parses registry -> decodes `.alm_trace.bin` & `.alm_rt_trace.bin`.
#
# [GRAMMAR]
#   Format    : <slot> <NAME> <owner> <meaning>
#   Ignored   : Blank lines, `#` comment lines.
#   Fields    :
#     slot    : u8 (0..=255), unique. 1 byte per ring event.
#     NAME    : [A-Z0-9_]+, unique. Maps to `TRACE_<NAME>` in Rust.
#     owner   : Single token (compiler | parser | checker | analyzer | lowerer |
#               backend | runtime | cbridge | chost | cross).
#     meaning : Free text (rest of line, verbatim).
#
# [LIFECYCLE & ALLOCATION]
#   Allocate  : Append 1 line on an unused slot; invoke via existing poke helpers.
#   Stability : Slots retain assigned numbers. Double-booking fails build.
#   Retire    : 0 poke sites remaining       -> delete line (slot freed).
#               Unreachable but still poked  -> keep booked.
#
# [BINARY PLATES]
#   1. Compiler Plate (`.alm_trace.bin`)
#      Type     : Overwriting event ring (FIFO wrap at capacity).
#      Layout   : [ total_events: u32 ][ capacity: u32 (8192) ][ events: u8[capacity] ]
#      Semantics: 1 fire = 1 event byte in fire order. No counts, no scope sections.
#
#   2. Runtime Sidecar Plate (`.alm_rt_trace.bin`)
#      Type     : Sticky byte array (256 bytes, 1 per slot).
#      Storage  : CWD-relative, mmap(MAP_SHARED), unlinked per run (anti-sticky).
#      IPC      : Multiple runtime copies in one process join a single plate via
#                 `/proc/self/maps` witness.
#
# [ANALYZER POKE SEMANTICS]
#   signal!   : Fires on the recording walk only.
#   probe()   : Collects into a set across fixpoint passes; flushes 1 mark per
#               signal at fixpoint exit (labeled "convergence-only" below).
#
# [DETERMINISM INVARIANT]
#   Two runs of an identical case MUST decode byte-identical.
